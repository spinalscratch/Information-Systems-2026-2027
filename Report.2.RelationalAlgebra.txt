Schema
------
  employees    (emp_no, birth_date, first_name, last_name, gender)
  departments  (dept_no, dept_name)
  dept_emp     (emp_no, dept_no, from_date, to_date)
  dept_manager (dept_no, emp_no, from_date, to_date)
  titles       (emp_no, title, from_date, to_date)
  salaries     (emp_no, salary, from_date, to_date)

      employees

Q2. All info of all departments
-------------------------------------------------------------------------------
      departments

-------------------------------------------------------------------------------
Q3. Full names of all employees
-------------------------------------------------------------------------------
      π first_name, last_name (employees)

-------------------------------------------------------------------------------
Q4. Names of all departments
-------------------------------------------------------------------------------
      π dept_name (departments)

Q5. Full names of employees working in the "ICT" department
-------------------------------------------------------------------------------
      π first_name, last_name (
            employees ⋈ dept_emp ⋈ σ dept_name = 'ICT' (departments) )

  (the selection is applied to departments before the join, so the joins
   work on one department only instead of all of them)

-------------------------------------------------------------------------------
Q6. Full names of male employees working in the "BIO" department
-------------------------------------------------------------------------------
      π first_name, last_name (
            σ gender = 'M' (employees)
            ⋈ dept_emp
            ⋈ σ dept_name = 'BIO' (departments) )

-------------------------------------------------------------------------------
Q7. Salaries of female employees working in the "WEO" department
-------------------------------------------------------------------------------
      F_WEO  ←  π emp_no (
                    σ gender = 'F' (employees)
                    ⋈ π emp_no, dept_no (dept_emp)
                    ⋈ σ dept_name = 'WEO' (departments) )

      Result ←  π emp_no, salary, from_date, to_date ( F_WEO ⋈ salaries )

-------------------------------------------------------------------------------
Q8. Full names of employees who have the same last name as their manager
-------------------------------------------------------------------------------
  "Their manager" = a manager of a department the employee works in.

      ED  ←  π emp_no, first_name, last_name, dept_no (
                 employees ⋈ π emp_no, dept_no (dept_emp) )

      MD  ←  ρ MD(mgr_no, mgr_last_name, dept_no) (
                 π emp_no, last_name, dept_no (
                     employees ⋈ π emp_no, dept_no (dept_manager) ) )

      Result ← π first_name, last_name (
                 σ last_name = mgr_last_name ∧ emp_no ≠ mgr_no ( ED ⋈ MD ) )

  ED ⋈ MD joins only on dept_no (the renaming makes the other attribute
  names different). emp_no ≠ mgr_no removes the managers themselves.

Q9. Full names of employees who were paid more than $100000

      π first_name, last_name (

Q10. Names of all departments that have employees paid more than $1000000
-------------------------------------------------------------------------------
      Rich   ←  π emp_no ( σ salary > 1000000 (salaries) )

      Result ←  π dept_name (
                    departments ⋈ π emp_no, dept_no (dept_emp) ⋈ Rich )
