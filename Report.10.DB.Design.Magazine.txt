Report.10 - DB Design: Magazines
Mario D'Occhio - 2640030

   Magazine(MagazineID, Title, ISSN, Number, Year)
   Article(Title, PageBegin, PageEnd, MagazineID)
   Author(AuthorID, Name, Email, Ascription)
   ArticleAuthors(ArticleTitle, AuthorID, OrderAuthor)

   - Article.Title is the key (no two articles have the same title)
   - the n-n relationship becomes the table ArticleAuthors,
     key (ArticleTitle, AuthorID), with the order of the author

   +------------+       +------------+       +----------------+       +------------+
   |  Magazine  |1     n|  Article   |1     n| ArticleAuthors |n     1|   Author   |
   |------------|-------|------------|-------|----------------|-------|------------|
   | MagazineID |       | Title      |       | ArticleTitle   |       | AuthorID   |
   | Title      |       | PageBegin  |       | AuthorID       |       | Name       |
   | ISSN       |       | PageEnd    |       | OrderAuthor    |       | Email      |
   | Number     |       | MagazineID |       +----------------+       | Ascription |
   | Year       |       +------------+                                +------------+
   +------------+
