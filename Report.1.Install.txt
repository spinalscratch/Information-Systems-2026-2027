-------------------------------------------------------------------------------
 1. Install MySQL
-------------------------------------------------------------------------------

$ brew install mysql
  (Homebrew download / installation log omitted)

$ brew services start mysql
==> Successfully started `mysql` (label: homebrew.mxcl.mysql)

$ mysql --version
mysql  Ver 9.x.x for macos on arm64 (Homebrew)        <-- exact version may differ

Set a password for the root user (answer the questions of the wizard):

$ mysql_secure_installation

Check that the server answers:

$ mysql -u root -p -e "SELECT VERSION();"
Enter password:
+-----------+
| VERSION() |
+-----------+
| 9.x.x     |
+-----------+

employees.sql creates the database "employees" with 6 tables (employees,
departments, dept_emp, dept_manager, titles, salaries) and 2 views
(dept_emp_latest_date, current_dept_emp), then loads the data from the
load_*.dump files with "source".

-------------------------------------------------------------------------------
 5. Notes
-------------------------------------------------------------------------------

- On macOS with Homebrew the server runs as a background service
  (brew services start/stop mysql); no sudo is needed.
- The README of test_db lists test_employees_md5.sql as the usual check, but
  MD5() was removed in MySQL 9.6, so test_employees_sha2.sql is used here.
- The database is used in the following labworks (Labwork 2, 3, 4).
